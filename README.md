# Traductor de pantalla · Screen Translator

**Español.** App para Android que traduce entre inglés y español lo que ves, escribes y escuchas en tu teléfono. Todo se procesa dentro del teléfono.

**English.** Android app that translates between Spanish and English what you see, type and hear on your phone. Everything is processed inside the phone.

## Descargar · Download

- Página con la guía paso a paso · Page with the step-by-step guide: https://d4tabl3-creator.github.io/traductor-descargas/
- Instalador directo · Direct installer: https://github.com/d4tabl3-creator/traductor-descargas/releases/latest/download/traductor-pantalla.apk

Requiere Android 11 o más nuevo. No funciona en iPhone.
Requires Android 11 or newer. It does not work on iPhone.
